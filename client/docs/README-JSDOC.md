> **Complete JavaScript documentation for InsightHub frontend (Vue.js) and backend (Node.js/Express)**

## 📚 Documentation Overview

This JSDoc documentation covers all JavaScript functions, classes, and modules across the entire InsightHub application stack.

### Frontend (Client)
- **Services**: API client, loading state, logging
- **Composables**: Snackbar notifications, locale switching
- **Configuration**: Navigation, dashboard access, theme management
- **Utilities**: Date formatting, helpers

### Backend (Server)
- **Controllers**: HTTP request handlers (surgical guide reports, etc.)
- **Models**: Database query builders
- **Services**: Business logic, Casbin authorization, logging
- **Middleware**: Authentication, security, error handling
- **Configuration**: Environment config, database connections

## 🔍 Navigation

Use the sidebar to browse:
- **Modules** - Organized code modules
- **Classes** - Controllers, Models, Services
- **Global Functions** - Utility functions and helpers
- **Namespaces** - API services

## 📖 Documentation Standards

Each function includes:
- ✅ **Description** - What it does
- ✅ **Parameters** - Types and descriptions
- ✅ **Returns** - Return type and value
- ✅ **Examples** - Usage code samples
- ✅ **Errors** - Error conditions

## 🚀 Getting Started

1. Browse the **Modules** section for organized features
2. Check **Classes** for object-oriented components
